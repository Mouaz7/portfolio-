## Skills and project icons

Every self-hosted Skills icon records its exact upstream URL, local path,
byte size, and SHA-256 digest in
[`docs/skill-icon-sources.json`](docs/skill-icon-sources.json). The sources in
that inventory currently include:

- [Simple Icons](https://github.com/simple-icons/simple-icons), whose project
  files are offered under CC0 1.0. Brand icons may still be governed by the
  relevant trademark owner's rules and by exceptions documented upstream.
- [Devicon](https://github.com/devicons/devicon), used from commit-pinned MIT
  releases for the colored development-tool icons.
- [Hugeicons](https://github.com/hugeicons/hugeicons-react), used through the
  Iconify API for two AI category symbols. The free Hugeicons package is
  distributed under the MIT license; its Pro assets are not included here.
- [Lucide](https://github.com/lucide-icons/lucide), used through Iconify for the
  Prompt Design symbol under the ISC license.
- Microsoft's SQL Database artwork, used as documentation of a listed skill
  under the [Azure Architecture Icons terms](https://learn.microsoft.com/en-us/azure/architecture/icons/#icon-terms).
  It is displayed unmodified next to its product label and is not used to
  represent this portfolio as a Microsoft product.

Project icons follow the same trademark limitation. GitHub, GitHub Actions,
React, Android, and all other product marks belong to their respective owners.
